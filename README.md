# AI Dev Skills

데이터가 주어지는 제한 시간 서비스 개발 과제를 위한 Codex 스킬 5종과 상시 규칙입니다. 절차를 늘리는 대신, 다음 단계로 넘어가기 전에 확인할 게이트를 둡니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `templates/AGENTS.md` | 작업 공간에 설치되는 상시 규칙. 게이트 G1~G4, 서버, 기록, 금지 사항 |
| `skills/1-kickoff` | 입력 파악 → 모호함 스캔 → 담당자 질문을 하나씩 → 답 반영 |
| `skills/2-prd` | 접근 방식 선택 → PRD → 별도 세션 검수 → 사람 승인 |
| `skills/3-core` | 작업 계획 → 핵심 로직 → 핵심 결과 검증. 디버깅 절차 포함 |
| `skills/4-build` | API → 변경·경계 시나리오 → 화면. 위임 규칙 포함 |
| `skills/5-finish` | 증거 규칙 → 원문 대조 → 처음부터 실행 → 제출 문서 → 서술형 대비 요약 |
| `setup.sh` | 작업 공간에 설치. 기존 파일을 덮어쓰지 않습니다 |
| `USAGE.md` | 사용 설명서. 설치부터 제출까지 단계별 입력문 |
| `RUNBOOK.md` | 터미널 배치, 시간표, 세션 관리, 문제 대응 |

## 설치

과제 작업 공간 루트에서 실행한 뒤 `codex`를 시작합니다.

```bash
git clone --depth 1 https://github.com/K1EH/skill /tmp/skill-kit && bash /tmp/skill-kit/setup.sh
```

## 게이트

| 게이트 | 통과 조건 |
| --- | --- |
| G1 입력 | 제공 데이터를 세거나, 데이터가 없으면 코드·API·입력 예시를 실행해 기록했다 |
| G2 설계 | 기준 입력, 근거가 있는 판정 기준, 숫자 완료 조건, 멈춤 조건을 사람이 승인했다 |
| G3 핵심 결과 | 실제 결과가 판정 기준(예상 범위, 사례 표, 통과율)을 통과했다 |
| G4 증거 | 완료라고 말하기 전에 실행 결과를 읽었다 |

특정 과제의 풀이 코드는 들어 있지 않습니다. 플랫폼 규칙과 과제 안내가 이 저장소의 지침보다 우선합니다. 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.
