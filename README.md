# AI Dev Skills v2

데이터가 주어지는 제한 시간 서비스 개발 과제를 위한 Codex 스킬 3종과 상시 규칙입니다. 절차를 늘리는 대신, 다음 단계로 넘어가기 전에 확인할 게이트를 둡니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `templates/AGENTS.md` | 작업 공간에 설치되는 상시 규칙. 게이트 G1~G4, 서버, 기록, 금지 사항 |
| `skills/1-kickoff` | 데이터 프로파일 → 모호함 스캔 → 담당자 질문을 하나씩 → 결정 기록 |
| `skills/2-build` | 설계 고정 → 핵심 로직과 규모 검증 → API → 화면. 위임 규칙 포함 |
| `skills/3-finish` | 원문 대조 → 처음부터 실행 → 제출 문서 → 서술형 대비 요약 |
| `setup.sh` | 작업 공간에 설치. 기존 파일을 덮어쓰지 않습니다 |
| `RUNBOOK.md` | 터미널 배치, 시간표, 세션 관리, 문제 대응 |

## 설치

과제 작업 공간 루트에서 실행한 뒤 `codex`를 시작합니다.

```bash
git clone -b v2 --depth 1 https://github.com/K1EH/skill /tmp/skill-kit && bash /tmp/skill-kit/setup.sh
```

## 게이트

| 게이트 | 통과 조건 |
| --- | --- |
| G1 데이터 | 제공 데이터를 스크립트로 세어 기록했다 |
| G2 설계 | 기준 데이터, 산식이 있는 예상 범위, 숫자 완료 조건, 멈춤 조건을 사람이 승인했다 |
| G3 규모 | 실제 결과 수와 분포가 예상 범위 안에 있다 |
| G4 증거 | 완료라고 말하기 전에 실행 결과를 읽었다 |

특정 과제의 풀이 코드는 들어 있지 않습니다. 플랫폼 규칙과 과제 안내가 이 저장소의 지침보다 우선합니다. 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.
